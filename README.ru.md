# Morse

**Аппаратный распознаватель азбуки Морзе для FPGA с выводом на 16-сегментный дисплей**

Синтезируемая реализация декодера азбуки Морзе на Verilog для FPGA. Однобитный вход (кнопка/ключ) декодируется в реальном времени конечным автоматом на основе измерения длительности импульсов: точка, тире, пауза между буквами, пауза между словами. Три варианта определения паузы обеспечивают устойчивость к особенностям ручного ввода. Распознанный символ переводится в 17-битный код 16-сегментного дисплея: поддерживаются буквы A–Z, цифры 0–9 и знаки пунктуации. В комплекте — тестбенч, симулирующий "HELLO WORLD".

## ■ Возможности

- ❖ **Декодирование в реальном времени** — определение точки/тире по длительности импульса на тактовой частоте 10 кГц
- ❖ **Подавление дребезга** — 10 мс фильтр для механических контактов
- ❖ **Три варианта определения паузы** — v1 (длинное нажатие), v2 (долгая тишина), v3/по умолчанию (адаптивный автопереключатель)
- ❖ **Полный набор символов** — A–Z, 0–9 и 14 знаков пунктуации/спецсимволов
- ❖ **Выход на 16-сегментный дисплей** — 17-битный код (16 сегментов + точка) для каждого декодированного символа
- ❖ **Готово к синтезу на FPGA** — синхронный дизайн с тактом и сбросом; тактирование через PLL для любой целевой частоты

## ■ Модули

<div align="center">

| Модуль | Файл | Описание |
|--------|------|----------|
| `morseio` | `morseIO.v` | Конечный автомат тайминга — измеряет длительности и извлекает последовательность точек/тире |
| `morseTR` | `morseTR.v` | Транслятор — преобразует (длину, паттерн) в 17-битный код 16-сегментного дисплея |
| `morseMain` | `morseMain.v` | Верхний уровень — соединяет `morseio` и `morseTR`, фиксирует выход по сигналу valid |
| `morse_tb` | `morseTest.v` | Тестбенч — симулирует "HELLO WORLD" в трёх вариантах |

</div>

## ■ Параметры тайминга

<div align="center">

| Параметр | Значение | Описание |
|----------|----------|----------|
| `Ns` | 10 мс | Минимальная длительность точки |
| `Nl` | 300 мс | Минимальная длительность тире |
| `Nw` | 600 мс | Порог паузы между словами/буквами |
| `Nsw` | 2000 мс | Таймаут сброса режима автопаузы |
| `Nd` | 10 мс | Окно подавления дребезга |
| `frq` | 10 кГц | Тактовая частота (задаётся через `define`) |

</div>

## ■ Варианты определения паузы

- **v1** — нажатие дольше `Nw` (600 мс) означает конец символа
- **v2** — тишина дольше `Nw` (600 мс) после любого нажатия означает конец символа
- **v3** *(по умолчанию)* — адаптивный: начинает в режиме v2; переключается в v1 при длинном нажатии (`>= Nw`), возвращается в v2 после очень длинного нажатия (`>= Nsw`)

<div align="center">

| Компонент | Технология |
|-----------|------------|
| HDL | Verilog |

## ■ Запуск

```bash
# Симуляция (вариант v3 по умолчанию)
iverilog -o a.out morseMain.v morseIO.v morseTR.v morseTest.v && vvp a.out

# Открыть осциллограммы
gtkwave dump.vcd

# Выбрать вариант при компиляции
iverilog -D v1 -o a.out morseMain.v morseIO.v morseTR.v morseTest.v && vvp a.out
```
